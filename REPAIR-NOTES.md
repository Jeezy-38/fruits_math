# Fruit Math V4.2 changes

Removed the teacher feature from the application: registration choice, login access, dashboards, classroom links and assignments. Parent/child gameplay and admin curriculum tools remain. Old teacher accounts and classroom records are retained only as historical data and cannot be used to access the app.

The supplied ZIP and the earlier repaired ZIP are preserved. This package includes source, tests, migrations, dependency lock files and compiled assets. Local credentials, databases, dependencies, logs and runtime caches are excluded. See README.md for setup and upgrade instructions.
